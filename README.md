<h2>📖 Overview</h2>

<p>
  Crime Radar is a real time crime reporting web application specially designed to enhance public saftey and awreness by breaking the bridge between civil people and law enforcement. Through Crime Radar,
  users can stay informed on nearby crime incidents, visualize crime patterns on an interactive maps,  and actively contribute to building safer and more aware communities. The platform leverages modern web 
  technologies to deliver fast, reliable, and location-based crime data. With an intuitive interface and real-time updates, Crime Radar aims to bridge the gap between information and action, helping individuals 
  and communities stay one step ahead.   
</p><br />

<h2>🚀 Features</h2>
<ul>
<li>Interactive Crime Map : Live visualization of crime incidents based on location.</li>
<li>Real-time Crime Reporting: Instantly report crimes as they happens.</li>
<li>Crime Analitic Dashboards: Graphical representation of crime trends and patterns.</li>
<li>Anonymous Crime Reporting: Submit crime reports securely without revealing your identity.</li>
<li>User Privacy: Ensure the security of users' private data.</li>
</ul><br />

<h2>🛠️ Tech Stack</h2>
<ul>
  <li>Frontend : React, Tailwind CSS</li>
  <li>Backend : Node js, Express js</li>
  <li>Database : MongoDB</li>
  <li>Other : Leaflet.js (Maps), PDFKit(PDF generation), Nodemailer(Email forwarding)</li>
</ul><br />
